1、 langchain 工具调用 和 llm function call 有什么区别？
    langchain 面向用户侧提供了简单、统一的信息输入格式，然后langchain将相关的信息转化大模型规定的、可以识别的信息格式，传递给大模型，大模型回应后，在模型返回的结果，传递给用户，在业务流程中定位为中间件，起到承上启下的作用，简化用户侧的工作。它自身并不具备直接工具调用的能力

2、 langchain 工具调用 的 速度是受到什么影响？
  从调用速度上分析，langchain 和 llm function call 调用速度，耗时没有什么区别；langchain只是把用户的输入进行封装后，传递给大模型，对比大模型调用工具多了一个封装的动作。影响工具调用速度还是大模型推理，工具响应执行，模型输出回复 这几部分的耗时。
